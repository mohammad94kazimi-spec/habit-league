# چالش عادت‌ها

اپ وب (PWA) برای برنامه‌ریزی روزانه + ساخت/ترک عادت + رقابت امتیازی لیگی بین چند نفر.
معماری کاملاً رایگان: **Supabase** (دیتابیس Postgres + احراز هویت + API، رایگان همیشگی) +
یک هاست استاتیک رایگان برای فایل‌های اپ (Cloudflare Pages یا GitHub Pages).
هیچ سروری نداری که نگهش داری — فقط چند فایل استاتیک که مستقیم با Supabase حرف می‌زنن.

## ۱) ساخت پروژه‌ی Supabase

1. به [supabase.com](https://supabase.com) برو، رایگان ثبت‌نام کن و یک پروژه‌ی تازه بساز.
2. از منوی سمت چپ برو به **SQL Editor**، محتوای فایل `schema.sql` را کامل کپی کن، پیست کن و **Run** بزن.
   این کار جدول‌ها، قوانین امنیتی (RLS) و توابع امتیازدهی را می‌سازد.
3. از **Project Settings → API**، دو مقدار را کپی کن:
   - `Project URL`
   - `anon public` key

   > نکته‌ی امنیتی: کلید `anon` برای استفاده در فرانت‌اند طراحی شده و افشای آن مشکلی ندارد —
   > تمام محدودیت‌های دسترسی از طریق RLS در خود دیتابیس اعمال می‌شود، نه با مخفی نگه‌داشتن این کلید.

4. (اختیاری ولی توصیه‌شده) از **Authentication → Providers**، اگر نمی‌خوای اعضای لیگ ایمیلشون
   را تایید کنن، گزینه‌ی *Confirm email* را در **Authentication → Sign In / Providers → Email**
   خاموش کن تا بلافاصله بعد از ثبت‌نام وارد اپ بشن.

## ۲) وصل کردن اپ به Supabase

فایل `config.js` را باز کن و این دو مقدار را جایگزین کن:

```js
window.APP_CONFIG = {
  SUPABASE_URL: "https://xxxxxxxx.supabase.co",
  SUPABASE_ANON_KEY: "eyJhbGciOi....",
};
```

## ۳) هاست رایگان (Cloudflare Pages)

1. یک ریپوی تازه در GitHub بساز و همه‌ی فایل‌های این پوشه (`index.html`, `style.css`, `app.js`,
   `config.js`, `manifest.json`, `sw.js`, `icons/`) را داخلش push کن.
2. به [pages.cloudflare.com](https://pages.cloudflare.com) برو، با GitHub وارد شو، ریپو را انتخاب کن.
3. تنظیمات build را همین‌طور خالی بگذار (این یک سایت استاتیک ساده است، نیازی به build نیست) —
   فقط "Deploy".
4. چند ثانیه بعد یک آدرس مثل `habit-league.pages.dev` می‌گیری. همین آدرس را روی هر دو گوشی
   باز کنید و از منوی کروم گزینه‌ی **افزودن به صفحه‌ی اصلی** را بزنید تا مثل یک اپ نصب بشه.

> جایگزین: GitHub Pages هم دقیقاً همین‌جوری کار می‌کنه (Settings → Pages → انتخاب برنچ).

## ۴) استفاده

1. هر نفر (مثلاً تو و همسرت) جدا ثبت‌نام می‌کنید.
2. نفر اول یک لیگ می‌سازه (تب اولیه‌ی بعد از ورود) و کد دعوت شش‌رقمی می‌گیره.
3. نفر دوم با همون کد به لیگ می‌پیوندد.
4. هرکس عادت‌های خودش را در تب «عادت‌ها» تعریف می‌کنه (ایجاد عادت / ترک عادت).
5. هر روز در تب «امروز» وضعیت هر عادت را با ✓ یا ✕ ثبت می‌کنید.
6. امتیازها خودکار محاسبه می‌شن و در تب «لیگ» جدول امتیازات زنده رو می‌بینید.

## نحوه‌ی امتیازدهی (قابل تغییر در جدول `habits`)

- انجام موفق روزانه: `+۱` امتیاز پایه
- هر ۷ روز پیاپی موفق: `+۳` امتیاز پاداش استریک (و استریک با یک شکست ریست می‌شه)
- لغزش/عدم انجام: `−۱` امتیاز جریمه

این عددها (`base_points`, `penalty_points`, `streak_bonus_every`, `streak_bonus_points`) برای هر
عادت جدا در جدول `habits` قابل تغییرن — می‌تونی مستقیم از Supabase Table Editor ویرایششون کنی،
یا بعداً یک فرم تنظیمات به اپ اضافه کنیم.

## محدودیت‌های نسخه‌ی رایگان که باید بدونی

- **Supabase Free**: دیتابیس تا ۵۰۰ مگابایت (برای این اپ به‌راحتی کافیه)، و اگر پروژه **۷ روز**
  کاملاً بدون درخواست بمونه به حالت pause می‌ره — با اولین باز کردن اپ توسط هرکدوم از اعضا
  (که روزانه چک-این می‌کنید) خودکار فعال می‌مونه، پس در عمل مشکلی پیش نمیاد.
- **Cloudflare Pages / GitHub Pages**: رایگان همیشگی، بدون محدودیت زمانی.
- دسترسی از ایران به Supabase و Cloudflare معمولاً بدون فیلترشکن ممکنه، ولی چون این سرویس‌ها
  خارج از ایران هستن، ممکنه گاهی کیفیت اتصال نوسان داشته باشه. اگر در عمل با قطعی/کندی مکرر
  مواجه شدید، جایگزینی مثل هاست ایرانی (لیارا) با یک بک‌اند Flask هم گزینه‌ی قابل‌اجراست
  که در گفتگو دربارش صحبت کردیم.

## توسعه‌های بعدی که می‌شه اضافه کرد

- اعلان/یادآوری روزانه (Push Notification از طریق Web Push)
- تاریخچه و نمودار پیشرفت هر عادت
- چند لیگ هم‌زمان برای هر کاربر
- ویرایش امتیازدهی هر عادت از داخل خود اپ (نه فقط از Supabase)
